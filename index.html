About the Workshop

The workshop was first held in August 2024 for 60 students. Today it has trained 180 students with the help of 12 volunteer mentors from the department[span_0](start_span)[span_0](end_span).

A website is built one tag at a time.

— Workshop Convenor, during the inauguration[span_1](start_span)[span_1](end_span).

Aims and Objectives

  • Explain how a page reaches the browser: total time T = tDNS + trequest + trender[span_2](start_span)[span_2](end_span).
  • Build pages with valid and accessible HTML5 and organise them in a clean folder structure[span_3](start_span)[span_3](end_span).
  • Understand file sizes in bytes, where 1 KB = 210 bytes, before adding images and video[span_4](start_span)[span_4](end_span).

As our mentors often say, view source is the best teacher[span_5](start_span)[span_5](end_span).

What happens when a user opens this website

  1. The user types the URL into the browser (the client) and presses Enter[span_71](start_span)[span_71](end_span).
  2. The browser asks a DNS resolver for the IP address of workshop.example.edu[span_72](start_span)[span_72](end_span).
  3. Using that IP address, the browser sends an HTTPS request (GET /index.html) to the Web server[span_73](start_span)[span_73](end_span).
  4. The server finds the file and sends a response: status code 200 and the HTML document[span_74](start_span)[span_74](end_span).
  5. While reading the HTML, the browser sends further requests for the CSS, images and video[span_75](start_span)[span_75](end_span).
  6. The browser renders the page from the HTML, CSS and media files[span_76](start_span)[span_76](end_span).

Relative paths

  • images/workshop-hall.png in about.html: the browser joins it with the current folder, giving http://localhost:8000/images/workshop-hall.png[span_87](start_span)[span_87](end_span).
  • contact.html#office-hours: opens contact.html in the same folder and scrolls to the element with id="office-hours"[span_88](start_span)[span_88](end_span).

Development Environment

Editor: Visual Studio Code. Browser: Google Chrome. Local server: Python http.server (XAMPP Apache works the same way)[span_89](start_span)[span_89](end_span).

cd workshop-site
python -m http.server 8000
# open http://localhost:8000/index.html

After each change, I saved the file and refreshed the browser (Ctrl + R). The localhost screenshot is in the report[span_90](start_span)[span_90](end_span).

Hosting Recommendation

I recommend shared hosting. The site is small and static, traffic is a few hundred visits a day during the registration period, and shared hosting is the cheapest option with the least administration. A VPS or dedicated server gives more control and scalability, but the workshop does not need it[span_91](start_span)[span_91](end_span).

The domain name gives a readable address, DNS records (A record) point the name to the server’s IP address, the hosting server stores and serves the files, and the control panel manages files, SSL certificates and email[span_92](start_span)[span_92](end_span).

Security Considerations

  • Use HTTPS so form data is encrypted in transit[span_93](start_span)[span_93](end_span).
  • No passwords or secrets are placed in HTML comments or hidden inputs[span_94](start_span)[span_94](end_span)[span_95](start_span)[span_95](end_span).
  • Browser validation (required, pattern, min/max) helps users, but the server must validate again[span_96](start_span)[span_96](end_span).
  • Future database code must use parameterised queries to prevent SQL injection[span_97](start_span)[span_97](end_span).
  • Uploaded files must be checked for type and size and stored outside the web root[span_98](start_span)[span_98](end_span).
  • Any user input shown back on a page must be escaped to prevent XSS[span_99](start_span)[span_99](end_span).
  • The form collects only the data needed to reserve a seat[span_100](start_span)[span_100](end_span).
  • The hosting account uses a strong password and two-factor authentication[span_101](start_span)[span_101](end_span).
